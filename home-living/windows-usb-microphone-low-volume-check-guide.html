윈도우에서 USB 마이크 목소리가 너무 작게 녹음될 때

스피커 음량을 올리는 것보다 녹음에 쓰는 입력 장치와 입력 볼륨을 먼저 확인하세요. 노트북 내장 마이크가 선택돼 있을 수도 있어요. Windows의 마이크 테스트로 녹음한 뒤 같은 조건에서 앱 녹음과 비교하면 어디서 소리가 작아지는지 좁힐 수 있어요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 11월 14일

출처: Microsoft — 마이크 문제 해결 (Windows 11·10)

점검 순서

  1. 1. 실제로 녹음하는 마이크를 확인해요
  2. 2. 입력 볼륨을 조절하고 짧게 녹음해요
  3. 3. 마이크를 향한 방향도 살펴봐요
  4. 4. Windows 테스트와 앱 결과를 나눠 봐요
  5. 설정을 확인해도 작다면 결과를 모아 문의해요

1. 실제로 녹음하는 마이크를 확인해요

Windows 11에서 시작 → 설정 → 시스템 → 소리로 들어가 입력 장치를 살펴보세요. USB 마이크를 꽂았더라도 노트북이나 웹캠 마이크가 선택돼 있다면 사용할 USB 마이크로 바꿔요. 스피커를 고르는 출력 항목과 혼동하지 마세요.

이 글은 입력 장치로 인식되지만 녹음 음량이 작은 경우를 다뤄요. 장치 목록에 아예 없다면 케이블 연결과 장치 인식부터 확인해야 해요.

2. 입력 볼륨을 조절하고 짧게 녹음해요

입력에서 해당 마이크의 속성을 열고 마이크 테스트를 시작해요. 평소 말하는 크기로 이야기한 뒤 테스트를 멈추고 녹음된 소리를 들어보세요. 작다면 입력 볼륨을 조금 올려 같은 문장으로 다시 시험해요.

스피커 음량만 바꾸면 재생되는 크기가 달라져 비교하기 어려워요. 재생 음량과 말하는 위치를 일정하게 두고 한 번에 한 설정만 바꿔 보세요. 입력 볼륨을 무조건 최대로 올리는 것을 해결 기준으로 삼지 않아요.

3. 마이크를 향한 방향도 살펴봐요

Microsoft는 마이크 배치도 확인하도록 안내해요. 제품마다 소리를 받는 면이 다를 수 있으니 사용 중인 마이크 설명서에서 말하는 방향과 권장 위치를 확인하세요.

본체에 조절 다이얼이 있다면 마이크 입력용인지 이어폰 재생용인지부터 구분해요. 이름과 기능은 모델마다 달라요. 모든 USB 마이크에 같은 증폭 메뉴나 수치를 적용할 수 있다고 가정하지 마세요.

4. Windows 테스트와 앱 결과를 나눠 봐요

Windows 테스트는 괜찮은데 회의·녹음 앱에서만 작다면 앱이 선택한 입력 장치와 입력 음량 설정을 확인해요. 자동 음량 조절 기능이 있다면 현재 설정을 기록해 두고 앱의 공식 안내에 따라 비교해 보세요.

앱에서 전혀 녹음되지 않는다면 음량보다 마이크 접근 권한을 확인할 차례예요. Windows 설정의 개인정보 및 보안 → 마이크에서 해당 앱 유형의 접근을 허용했는지 살펴보세요. 녹음이 작다는 이유만으로 권한을 모두 바꾸거나 드라이버부터 삭제할 필요는 없어요.

설정을 확인해도 작다면 결과를 모아 문의해요

선택한 입력 장치, Windows 테스트 결과, 문제가 생기는 앱, 본체 다이얼 위치를 기록해 제조사에 문의해 보세요. 가능하면 다른 PC에서도 같은 마이크를 시험해 비교할 수 있어요. 한 번의 녹음만으로 마이크 고장이라고 단정하지 마세요.

설정으로 음량이 충분해졌다면 새 마이크를 살 필요는 없어요. 책상에서 말하는 거리나 수음 방향에 맞지 않아 바꿀 때는 관련 USB 마이크 비교글에서 탁상 구성과 수음 방향을 살펴보세요.
