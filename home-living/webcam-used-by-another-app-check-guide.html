생활 문제 해결 · 구매 전 점검

웹캠이 ‘다른 앱에서 사용 중’이라고 나올 때 해결 순서

다른 회의 앱이나 녹화 프로그램이 카메라를 잡고 있는지 먼저 확인하세요. 그래도 안 되면 PC를 다시 시작한 뒤 카메라 앱 하나만 열어 보세요. 같은 메시지라도 접근 권한이나 앱 설정이 관련될 수 있어, 웹캠 고장으로 바로 판단하지 않는 편이 좋아요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 13일

출처: Microsoft: Windows 카메라 오류와 앱 사용 충돌 점검, Microsoft: 카메라 앱 접근 권한과 데스크톱 앱의 차이

점검 순서

  1. 1. 카메라를 쓰는 앱을 닫고 다시 시작해요
  2. 2. Windows의 카메라 접근 권한을 확인하세요
  3. 3. 기본 카메라 앱과 회의 앱을 따로 시험해요
  4. 4. 어느 앱에서도 안 되면 연결과 업데이트를 봐요
  5. 교체 전에 어디서 안 되는지부터 정리하세요

1. 카메라를 쓰는 앱을 닫고 다시 시작해요

진행 중인 통화나 녹화를 마치고 필요한 작업을 저장하세요. 회의 앱, 녹화 프로그램, 영상 통화 중인 브라우저 탭을 닫은 뒤 원하는 앱 하나만 열어 봐요.

종료되지 않은 앱은 작업 관리자에서 확인할 수 있어요. 모르는 시스템 프로세스를 임의로 끝내지 말고, 어떤 앱인지 구분하기 어렵다면 PC를 다시 시작하세요. 절전에서 깨우는 것은 다시 시작과 달라요.

2. Windows의 카메라 접근 권한을 확인하세요

Windows 11에서 설정 → 개인정보 및 보안 → 카메라로 이동해요. ‘카메라 액세스’와 ‘앱에서 카메라에 액세스하도록 허용’이 켜져 있는지 확인하고, 목록에 있는 사용 앱의 권한도 살펴보세요.

인터넷에서 설치한 회의 앱이나 브라우저는 데스크톱 앱에 해당할 수 있어요. 이 경우 ‘데스크톱 앱에서 카메라에 액세스하도록 허용’도 확인해야 해요. Windows의 이 설정은 데스크톱 앱마다 따로 켜고 끄는 방식이 아니에요.

설정이 회색으로 잠겨 있다면 회사·학교 PC의 관리자에게 문의하세요. 앱 목록에 이름이 없다는 이유만으로 설치 오류라고 판단하지 마세요.

3. 기본 카메라 앱과 회의 앱을 따로 시험해요

다른 앱을 닫은 상태에서 시작 메뉴의 카메라 앱을 열어 미리보기가 나오는지 확인해요. 확인한 뒤에는 카메라 앱도 닫고 회의 앱을 다시 열어 보세요.

기본 앱에서는 보이는데 회의 앱에서만 안 된다면 그 앱의 카메라 선택과 권한 설정을 살펴볼 차례예요. 웹캠을 여러 개 연결했다면 의도한 장치를 선택했는지도 확인하세요.

4. 어느 앱에서도 안 되면 연결과 업데이트를 봐요

카메라의 물리 스위치나 가리개, USB 연결을 확인하세요. 외장 웹캠은 다른 USB 포트나 사용 가능한 다른 PC에서도 시험해 볼 수 있어요.

Windows의 도움말 앱에서 카메라 문제 해결사를 실행하고, Windows Update나 제조사 지원 페이지의 드라이버 안내를 확인해요. 회사 PC는 보안 설정을 임의로 해제하기보다 관리자에게 오류 문구와 발생 시점을 전달하세요.

교체 전에 어디서 안 되는지부터 정리하세요

특정 앱에서만 안 된다면 새 웹캠을 사기 전에 그 앱의 설정을 점검해요. 다른 PC에서도 작동하지 않거나 연결부가 손상됐다면 제조사에 상담할 근거가 돼요. 시험한 앱·PC와 오류 문구를 함께 남겨 두세요.

교체가 필요할 때는 아래 웹캠 비교글에서 연결 단자, 초점 방식, 화각을 살펴볼 수 있어요. 높은 해상도가 접근 권한이나 앱 충돌 문제를 해결해 주지는 않아요.
