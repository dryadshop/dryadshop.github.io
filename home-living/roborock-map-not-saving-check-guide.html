로보락이 청소할 때마다 지도를 새로 만들 때

지도 저장 기능이 있는 모델이라면 저장 설정과 첫 전체 청소가 끝났는지 먼저 확인해요. 로보락은 도크에서 출발해 필요한 공간을 모두 청소하고, 옮기지 않은 도크로 스스로 돌아오는 조건을 안내해요. 이미 있던 지도가 사라진 경우는 처음부터 저장되지 않는 경우와 나눠 보세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 26일

출처: Roborock: 첫 지도 작성과 저장 조건, Roborock: S5 Max 공식 FAQ

점검 순서

  1. 1. 처음부터 저장되지 않았는지 구분하세요
  2. 2. 지도 저장 설정이 켜져 있는지 봐요
  3. 3. 도크에서 출발해 전체 청소를 마쳐 보세요
  4. 4. 있던 지도가 사라졌다면 복구 가능 여부를 따로 확인해요
  5. 5. 같은 조건에서도 반복되면 기록을 모아 문의해요

1. 처음부터 저장되지 않았는지 구분하세요

청소할 때마다 집 구조를 새로 그리는지, 이전 지도는 있지만 방 구분만 달라졌는지 확인해요. 문제를 설명할 수 있도록 현재 지도와 청소 기록 화면을 남겨 두세요.

아래 점검은 지도 저장 기능이 있는 로보락과 해당 기능을 제공하는 앱을 전제로 해요. 참고한 S5 Max 공식 FAQ에도 지도 저장 안내가 있지만, 메뉴 이름과 지원 기능은 모델·앱·펌웨어에 따라 달라요. 같은 메뉴가 없으면 다른 모델의 설정을 억지로 따라 하지 마세요.

2. 지도 저장 설정이 켜져 있는지 봐요

공식 초기 지도 안내는 청소기 설정 또는 지도 편집에서 Map saved mode, 즉 지도 저장 모드를 켜도록 설명해요. 사용하는 모델의 앱에서 해당 설정이 제공되는지 확인하세요.

이미 켜져 있는데도 지도가 남지 않는다면 껐다 켜기를 반복하기보다 다음 단계의 청소 완료 조건을 확인해요. 이전 지도를 보존하고 싶다면 지도 삭제나 초기화 전에 해당 모델의 안내를 먼저 읽으세요.

3. 도크에서 출발해 전체 청소를 마쳐 보세요

첫 지도를 만들 때는 도크에서 시작하고 지도에 포함할 방의 문을 열어 두세요. 한 구역만 청소하고 끝내지 말고, 로봇이 감지한 공간을 모두 청소할 수 있게 해요.

청소 중 도크 위치를 바꾸지 않고 로봇이 스스로 도크에 돌아오도록 해요. 중간에 멈췄거나 사람이 옮겨 놓았다면 공식 안내의 완료 조건을 충족했는지 다시 확인하세요. 도크 복귀 자체에 실패한다면 지도 저장과 함께 복귀 실패 원인도 점검해야 해요.

4. 있던 지도가 사라졌다면 복구 가능 여부를 따로 확인해요

처음 지도를 저장하는 절차가 예전 방 구분과 진입 금지 구역까지 되돌려 주는 것은 아니에요. 새로 청소를 시작하기 전에 사용 모델의 지도 관리 안내에서 백업·복원 기능 유무와 현재 남아 있는 지도를 확인하세요.

청소 기록에 예전 그림이 보인다는 이유만으로 그것을 복구할 수 있다고 단정하지 마세요. 이 글은 모든 모델의 복원 방법을 다루지 않아요. 기능이나 삭제 영향이 불명확하다면 지원팀에 먼저 문의해요.

5. 같은 조건에서도 반복되면 기록을 모아 문의해요

저장 설정과 전체 청소·자동 복귀를 확인했는데 다음 청소에서 또 새 지도를 만든다면 로봇 모델, 앱 이름과 버전, 펌웨어 버전, 지도 변화 전후 화면을 준비해 로보락 지원에 문의하세요. 업데이트 직후 시작됐는지도 함께 알려 주세요.

지도 문제만으로 로봇이나 도크를 바로 바꿀 필요는 없어요. 점검 후 교체를 검토하게 되면 아래 로봇청소기 비교글에서 도크 기능과 설치 공간을 살펴보세요. 지도 저장과 복원 지원은 선택할 정확한 모델에서 별도로 확인해야 해요.
