외부 모니터 글자가 흐릿할 때, 해상도와 배율부터 확인하세요

글자를 크게 보려고 해상도를 낮췄다면 먼저 권장 해상도로 되돌려 보세요. 글자 크기는 배율로 조절할 수 있어요. 모든 화면이 흐린지 특정 앱만 흐린지도 구분해야 모니터 교체가 필요한지 판단하기 쉬워요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 18일

출처: Microsoft: Windows 화면 해상도와 배율 변경

점검 순서

  1. 1. 흐리게 보이는 모니터를 먼저 선택해요
  2. 2. 해상도를 권장값으로 맞추세요
  3. 3. 글자 크기는 배율에서 조절해요
  4. 4. 특정 앱에서만 흐린지 비교해 보세요
  5. 권장 해상도가 없거나 갑자기 달라졌다면

1. 흐리게 보이는 모니터를 먼저 선택해요

Windows 11에서 시작 → 설정 → 시스템 → 디스플레이로 이동하세요. 여러 화면이 연결돼 있다면 외부 모니터를 선택한 뒤 설정을 바꿔요. 노트북 화면만 바꾸고 외부 화면은 그대로 두는 실수를 피할 수 있어요.

2. 해상도를 권장값으로 맞추세요

배율 및 레이아웃의 디스플레이 해상도에서 ‘권장’ 표시를 확인하세요. Microsoft는 모니터의 기본 해상도보다 낮은 값을 쓰면 글자의 선명도가 떨어지거나 화면이 늘어날 수 있다고 안내해요. 설정 전 값을 기록해 두면 변경 결과를 비교하기 편해요.

3. 글자 크기는 배율에서 조절해요

권장 해상도에서 글자가 너무 작다면 같은 화면의 배율을 살펴보세요. 우선 권장값을 기준으로 읽기 편한지 확인해요. 해상도는 화면을 이루는 점의 수, 배율은 글자와 앱이 표시되는 크기를 조절하는 설정이에요.

4. 특정 앱에서만 흐린지 비교해 보세요

설정 화면과 평소 쓰는 문서·브라우저를 같은 모니터에서 비교해요. 특정 앱에서만 흐리다면 앱 이름과 버전, 어느 화면으로 옮겼을 때 달라지는지 기록해 해당 앱의 지원 안내를 확인하세요. 화면 전체가 흐린 경우와 같은 원인으로 단정하지 않아요.

권장 해상도가 없거나 갑자기 달라졌다면

모니터·노트북 모델, 연결 단자, 케이블·허브 구성과 현재 해상도를 정리하세요. 해상도가 예상과 다르게 바뀐 경우 Microsoft는 Windows Update에서 그래픽 드라이버 업데이트를 확인하도록 안내해요. 설치해도 달라지지 않으면 PC·모니터 제조사에 연결 구성이 지원되는지 문의하세요.

설정으로 모든 패널의 글자 표현을 같게 만들 수는 없어요. 점검 후에도 문서 작업에 맞지 않아 교체를 고려한다면 아래 업무용 모니터 비교글에서 화면 크기와 해상도를 함께 살펴보세요. 이 글은 macOS 설정을 다루지 않아요.
