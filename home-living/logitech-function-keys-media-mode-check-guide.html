생활 문제 해결 · 구매 전 점검

로지텍 키보드 F1~F12가 밝기·음량 키로 작동할 때

F키를 눌렀을 때 음량이나 밝기가 바뀐다면 키 입력이 아예 안 되는 상태와는 달라요. 미디어 기능이 먼저 실행되도록 설정됐는지 살펴보세요. MX Mechanical은 Fn + Esc로 미디어 키와 F키 동작을 전환할 수 있어요. 다른 모델은 같은 조합을 지원하는지 설명서부터 확인해 주세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 11월 14일

출처: Logitech MX Mechanical 시작 안내 — F-keys switch, Logitech 기본 기능키 사용 안내

점검 순서

  1. 1. 모델명과 실제로 실행되는 기능을 확인해요
  2. 2. 지원 모델에서 Fn 잠금을 전환해요
  3. 3. Logi Options+를 지원하면 기본 기능키 설정을 봐요
  4. 4. 한 앱에서만 다른지 구분해요
  5. 바꾸기 전에 확인 결과를 남겨요

1. 모델명과 실제로 실행되는 기능을 확인해요

키보드 밑면의 모델명을 확인하고 F키를 눌렀을 때 어떤 동작이 나오는지 적어 보세요. 소리가 커지거나 화면 밝기가 바뀐다면 미디어 기능이 실행된 경우예요. 아무 반응이 없는 키, 글자가 두 번 입력되는 증상과는 점검 방향이 달라요.

이 글의 단축키 예시는 MX Mechanical 공식 안내를 기준으로 해요. 모든 로지텍 키보드나 노트북 내장 키보드에 같은 조합을 적용하지 마세요.

2. 지원 모델에서 Fn 잠금을 전환해요

MX Mechanical에서는 Fn 키를 누른 채 Esc를 한 번 눌러 보세요. 미디어 기능과 F키 중 어느 쪽을 기본으로 쓸지 바뀌어요. 전환한 뒤 사용하던 앱에서 필요한 F키가 원하는 대로 동작하는지 확인해요.

설정이 반대로 바뀌었다면 같은 조합으로 다시 전환할 수 있어요. 설명서에 이 조합이 없는 모델에서는 다른 키를 임의로 길게 누르지 말고 해당 모델의 기능키 안내를 찾아보세요.

3. Logi Options+를 지원하면 기본 기능키 설정을 봐요

사용 중인 키보드가 Logi Options+ 지원 모델이라면 앱에서 그 키보드를 선택한 뒤 설정을 확인해요. F1, F2 등을 표준 기능키로 사용하는 항목이 있으면 원하는 방식으로 설정할 수 있어요. 메뉴의 표현과 지원 범위는 모델과 앱 버전에 따라 달라요.

이미 설정을 바꿨다면 Fn 잠금도 반복해서 바꾸기보다 현재 상태에서 같은 키를 시험해 보세요. 회사 PC에서 앱 설치가 제한돼 있다면 관리자 정책을 확인하고, 지원하는 하드웨어 단축키부터 활용해요.

4. 한 앱에서만 다른지 구분해요

기본 F키 동작으로 바꿔도 특정 앱에서만 예상과 다르다면 그 앱의 단축키 설정과 키보드에 지정한 기능을 함께 살펴보세요. F키에 연결된 명령은 앱마다 같지 않아요. 이 단계는 고장을 확정하는 방법이 아니라 키보드 전체 문제인지 범위를 좁히는 점검이에요.

바꾸기 전에 확인 결과를 남겨요

설정을 바꾸어 필요한 F키가 동작한다면 새 키보드를 살 필요는 없어요. 지원되는 전환 방법을 확인했는데도 여러 앱에서 같은 키가 반응하지 않으면 모델명, 운영체제, 연결 방식과 시험한 내용을 정리해 로지텍 지원에 문의해 보세요.

키 배열이나 크기까지 바꿀 이유가 있을 때는 관련 기계식 키보드 비교글에서 풀배열·텐키리스·75% 배열의 차이를 살펴볼 수 있어요. 이 글의 설정을 해결하기 위한 필수 구매 목록은 아니에요.
