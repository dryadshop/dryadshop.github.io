문을 닫아도 도어락이 자동으로 잠기지 않을 때

자동 잠금 설정이 바뀌었는지, 건전지가 부족한지, 잠금쇠가 걸리는지 나눠 확인해 보세요. 소리가 났다는 것만으로 잠겼다고 판단하면 안 돼요. 아래는 솔리티 TR812 설명서 기준이며, 다른 도어락에 같은 버튼 순서나 경고음을 적용하지 마세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 23일

출처: 솔리티 TR812 공식 사용설명서 — 자동 잠금·건전지·데드볼트 걸림

점검 순서

  1. 1. 외출 전에 실제 잠금 상태를 확인하세요
  2. 2. 자동·수동 설정부터 살펴보세요
  3. 3. 건전지 경고와 삽입 상태를 확인하세요
  4. 4. 잠금쇠가 걸리면 힘으로 밀지 마세요
  5. 5. 반복되는 실패는 설치점에 점검을 맡기세요

1. 외출 전에 실제 잠금 상태를 확인하세요

문을 닫은 뒤 잠금쇠가 정상적으로 작동했는지 확인하세요. 잠겼는지 확신할 수 없다면 그대로 두고 외출하지 말고 설치점이나 관리실에 도움을 요청하세요. 이 글은 문이 닫혀도 잠기지 않는 문제를 다루며, 잠긴 문을 강제로 여는 방법은 다루지 않아요.

2. 자동·수동 설정부터 살펴보세요

TR812는 수동 잠금으로 설정하면 문을 닫는 것만으로 잠기지 않아요. 사용 중인 모델의 설명서에서 자동·수동 잠금 항목을 찾아 현재 설정을 확인하세요. 비밀번호 등록이나 초기화 메뉴와 혼동하지 말고, 모델이 다른 설명서의 숫자 조합은 입력하지 마세요.

3. 건전지 경고와 삽입 상태를 확인하세요

TR812 설명서는 자동 잠금이 안 될 때 설정과 건전지를 확인하도록 안내해요. 방전되면 동작음만 나고 작동하지 않을 수도 있어요. 교체할 때는 지정 규격과 극성을 지키고 전부 새것으로 바꾸세요. 오래된 건전지와 새 건전지, 서로 다른 제조사의 건전지를 섞지 마세요.

4. 잠금쇠가 걸리면 힘으로 밀지 마세요

문이 끝까지 닫히는지 살펴보고, 잠금쇠가 움직이다 걸리는 소리나 경고가 반복되는지 확인하세요. TR812는 잠금쇠인 데드볼트가 정상적으로 움직이지 못할 때 걸림 경고가 날 수 있어요. 설정 문제와 설치 위치 문제를 구분하려면 점검이 필요해요. 잠금쇠를 억지로 누르거나 설치 나사를 풀어 위치를 바꾸지 마세요.

5. 반복되는 실패는 설치점에 점검을 맡기세요

설정과 건전지를 확인해도 잠금이 실패하거나 걸림 경고가 반복되면 설치점·고객센터에 문의하세요. 모델명과 경고가 나는 시점, 문이 닫히는 상태를 알려주세요. 교체가 필요하다고 확인된 경우에는 아래 도어락 비교글을 참고하되 문 두께와 기존 타공에 맞는지는 설치 담당자에게 확인해야 해요.
