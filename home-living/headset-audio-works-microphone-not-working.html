헤드셋 소리는 들리는데 마이크만 안 될 때

소리가 들리는 것과 마이크가 선택된 것은 별개예요. 헤드셋의 음소거를 확인한 뒤 Windows에서 입력 장치를 골라 녹음해 보세요. 여기서 목소리가 들리면, 통화 앱의 장치 설정과 권한을 다음으로 살펴보면 돼요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 17일

출처: Microsoft 지원: 마이크 문제 해결 — Windows 11 입력·테스트·권한, Microsoft 지원: Teams에서 USB-C 헤드셋과 오디오 장치 설정

점검 순서

  1. 1. 음소거와 연결 상태를 확인해요
  2. 2. 출력이 아닌 입력 장치를 골라 테스트해요
  3. 3. 통화 앱이 같은 마이크를 쓰는지 봐요
  4. 4. 필요한 앱의 마이크 권한을 확인해요
  5. 녹음 결과를 남기고 다음 조치를 정해요

1. 음소거와 연결 상태를 확인해요

헤드셋이나 케이블에 있는 음소거 버튼을 살펴보세요. 통화 앱에서도 마이크가 꺼져 있지 않은지 확인해요. 플러그는 제대로 꽂혀 있는지, Bluetooth 제품은 PC에 연결된 상태인지도 점검하세요. 이 글의 설정 경로는 Windows 11 기준이에요.

2. 출력이 아닌 입력 장치를 골라 테스트해요

설정 → 시스템 → 소리에서 입력 항목을 찾아 헤드셋 마이크를 선택하세요. 해당 장치의 속성을 열어 마이크 테스트를 시작하고 짧게 말한 뒤 녹음 결과를 들어보세요. 메뉴 이름은 Windows 버전에 따라 조금 다를 수 있어요.

목소리가 작다면 마이크 위치와 입력 볼륨을 확인해요. 장치가 목록에 없는 경우와 목록에는 있지만 녹음이 안 되는 경우를 나눠 적어 두세요.

3. 통화 앱이 같은 마이크를 쓰는지 봐요

Windows 테스트에서는 녹음되는데 회의에서만 안 들린다면 앱의 마이크 선택을 살펴보세요. Teams를 쓴다면 장치 설정에서 스피커와 마이크를 각각 확인해요. 듣는 소리는 헤드셋으로 나오면서 목소리는 다른 마이크에서 받도록 되어 있을 수 있어요.

Microsoft의 USB-C 헤드셋 안내도 Teams 안에서 오디오 장치를 선택하는 과정을 따로 다뤄요. 다른 앱에서는 해당 앱의 오디오 설정을 확인하되, 특정 헤드셋의 버튼 색상이나 조작법을 그대로 적용하지 마세요.

4. 필요한 앱의 마이크 권한을 확인해요

설정 → 개인 정보 및 보안 → 마이크에서 마이크 접근과 앱 사용 권한을 확인하세요. 데스크톱 앱은 별도 허용 항목이 있어요. 회사나 학교에서 관리하는 PC에서 설정이 잠겨 있다면 관리자에게 문의해야 해요.

녹음 결과를 남기고 다음 조치를 정해요

입력 장치가 계속 보이지 않거나 테스트에 실패한다면 Windows의 소리 문제 해결과 제조사 지원 안내를 확인하세요. 드라이버 설치가 필요할 때는 PC 또는 헤드셋 제조사의 공식 경로를 이용하는 편이 좋아요.

상담할 때 모델명, USB·3.5mm·무선 중 연결 방식, 장치 목록 표시 여부와 녹음 결과를 함께 알려 주세요. 앱 하나에서만 발생하는 문제로 헤드셋부터 바꾸지는 마세요. 수리나 교체가 필요해졌다면 아래 비교글에서 PC의 연결 단자와 맞는 제품을 살펴볼 수 있어요.
