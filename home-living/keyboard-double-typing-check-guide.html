키보드를 한 번 눌렀는데 두 번 입력될 때 확인 순서

중복 입력만으로 키보드 스위치 고장이라고 단정할 수는 없어요. 먼저 다른 앱에서도 같은 글자가 반복되는지 보고, USB 연결과 다른 컴퓨터에서의 반응을 비교해 보세요. 설정·연결·기기 중 어느 쪽을 더 확인할지 좁힐 수 있어요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 21일

출처: Logitech 공식 지원: 키 중복 입력·USB 직결·다른 PC 비교

  3. 3. 가능하면 다른 컴퓨터와 비교해요
  4. 4. 모델에 맞는 관리·업데이트만 진행해요
  5. 반복되는 조건을 정리해 수리를 문의해요

1. 다른 앱에서도 같은 키를 눌러보세요

게임에서만 생긴다면 메모장에서도 확인해요. Logitech은 특정 프로그램에서만 키가 이상하게 반응하면 다른 프로그램으로 비교하도록 안내해요. 한 앱에서만 반복되면 그 앱의 키 지정이나 매크로 설정을 살펴보세요.

2. USB 허브를 거쳤다면 컴퓨터에 직접 연결해요

유선 키보드나 USB 수신기를 쓰고 있다면 허브·연장 장치 대신 컴퓨터에 직접 꽂아 확인하세요. Windows에서는 다른 USB 포트도 비교해 볼 수 있어요. Bluetooth 방식이라면 USB 수신기 점검은 해당하지 않아요.

3. 가능하면 다른 컴퓨터와 비교해요

같은 키보드가 다른 컴퓨터에서는 정상인지 확인해 보세요. 정상이라면 원래 컴퓨터의 연결이나 소프트웨어를 더 살펴볼 이유가 돼요. 두 컴퓨터에서 모두 반복되더라도 이 결과만으로 고장 부품을 특정할 수는 없어요.

4. 모델에 맞는 관리·업데이트만 진행해요

이물질 제거는 모델별 청소 안내를 따르세요. 분해하거나 스위치에 액체를 넣지 마세요. 업데이트는 공식 지원 페이지에서 모델과 운영체제를 확인해 진행해요.

Logitech은 기존 Firmware Update Tool 지원을 종료했어요. 오래된 설치 파일 대신 보유 모델의 현재 지원 프로그램을 확인하세요. 모든 키보드가 같은 앱을 쓰지는 않아요.

반복되는 조건을 정리해 수리를 문의해요

문제가 생기는 키·앱·연결 방식과 다른 PC의 결과를 정리해 점검을 문의하세요. 다른 브랜드의 청소·펌웨어 절차는 해당 제조사 안내를 따라야 해요. 교체가 필요하다면 아래 배열 비교글에서 숫자패드와 방향키 배치를 살펴보세요.
