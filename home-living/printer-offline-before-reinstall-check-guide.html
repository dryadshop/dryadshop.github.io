프린터가 오프라인으로 뜰 때, 재설치 전에 확인할 것

오프라인 표시는 프린터를 바꿔야 한다는 뜻은 아니에요. 전원과 연결 상태를 살펴본 뒤, 인쇄할 프린터가 맞는지와 멈춰 있는 작업이 있는지 확인해 보세요. 이 글은 Windows 11을 기준으로 안내해요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 19일

출처: Microsoft: Windows에서 오프라인 프린터 문제 해결, Microsoft: 프린터 연결 및 인쇄 문제 해결

점검 순서

  1. 1. 전원과 연결부터 살펴봐요
  2. 2. Windows의 프린터 문제 해결사를 실행해요
  3. 3. 출력 대상과 대기열을 확인하세요
  4. 4. 재설치는 모델과 연결 정보를 확인한 뒤 진행해요
  5. 새 프린터를 고르기 전에

1. 전원과 연결부터 살펴봐요

프린터 화면에 용지 걸림이나 덮개 열림 같은 오류가 있는지 보세요. 오류가 없다면 전원을 끄고 플러그를 뺀 뒤 약 30초 후 다시 연결해요. USB 방식은 케이블 양쪽을, Wi-Fi 방식은 컴퓨터와 프린터가 같은 네트워크에 연결돼 있는지 확인하세요.

2. Windows의 프린터 문제 해결사를 실행해요

Windows 11의 도움말 보기 앱에서 프린터 문제 해결사를 실행해 보세요. 안내를 마친 뒤 문서 한 장을 보내 결과를 확인해요. 같은 문서를 여러 번 보내면 연결이 복구됐을 때 중복 출력될 수 있어요.

3. 출력 대상과 대기열을 확인하세요

설정의 Bluetooth 및 장치에서 프린터 및 스캐너를 열고 사용할 기기를 선택해요. 앱의 인쇄 창에서도 같은 기기를 골랐는지 살펴보세요. 기본 프린터 지정이 필요하면 Windows의 자동 관리 설정을 먼저 확인해요.

인쇄 대기열에 멈춘 작업이 있다면 다시 출력할 원본을 확보한 뒤 해당 작업을 취소해요. 회사 공유 프린터라면 다른 사람의 작업을 임의로 취소하지 말고 관리자에게 문의하세요.

4. 재설치는 모델과 연결 정보를 확인한 뒤 진행해요

앞선 점검으로 해결되지 않을 때 제조사 안내에 따라 드라이버나 재설치를 검토해요. 모델명, USB·Wi-Fi 연결 방식, Windows 버전과 오류 화면을 준비하면 상담에 도움이 돼요. ARM 기반 PC는 설치 방식이 다를 수 있어 Microsoft의 별도 안내를 확인하세요.

새 프린터를 고르기 전에

연결 문제만으로 잉크나 프린터를 새로 살 필요는 없어요. 점검 후 교체하기로 했다면 아래 가정용 프린터 비교글에서 출력 방식과 연결 조건을 살펴보세요.
