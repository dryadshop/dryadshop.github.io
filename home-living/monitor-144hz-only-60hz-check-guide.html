144Hz 모니터인데 60Hz만 나올 때 확인 순서

모니터가 144Hz를 지원해도 현재 해상도와 연결 단자 조합에서는 60Hz만 선택될 수 있어요. Windows에서 선택한 화면과 주사율을 먼저 확인하고, 모니터 입력·컴퓨터 출력·중간 연결 장치가 같은 조건을 지원하는지 순서대로 살펴보세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 11일

출처: Microsoft 지원 · Windows 모니터 주사율 변경, Intel 지원 · 1920×1080 144Hz 출력 조건

점검 순서

  1. 1. 바꾸려는 모니터가 선택되어 있는지 봐요
  2. 2. 제품명보다 단자별 지원 표를 확인해요
  3. 3. 허브가 있다면 연결 경로를 하나씩 확인해요
  4. 4. 지원 조건은 맞는데 목록이 없으면 정보를 모아요
  5. 5. 부족한 연결 구간을 확인한 뒤 교체해요

1. 바꾸려는 모니터가 선택되어 있는지 봐요

주사율은 화면을 1초에 몇 번 새로 그리는지 나타내는 값이에요. Windows 11에서는 설정 → 시스템 → 디스플레이 → 고급 디스플레이로 들어가요. 화면을 여러 개 연결했다면 문제가 있는 외부 모니터를 선택하세요.

현재 해상도와 새로 고침 빈도를 확인한 뒤 목록에 144Hz가 있는지 봐요. 지원되는 값이 보이면 선택해 보세요. 별표가 붙은 값은 현재 해상도를 유지할 수 없는 조합일 수 있으므로, 적용 후 해상도도 함께 확인해야 해요.

2. 제품명보다 단자별 지원 표를 확인해요

모니터 설명서에서 현재 쓰는 HDMI 또는 DisplayPort 입력이 원하는 해상도와 144Hz를 함께 지원하는지 찾아보세요. 이어서 컴퓨터의 해당 출력 단자도 같은 조건을 지원하는지 확인해요.

Intel의 안내도 고주사율 출력에는 입력과 출력 양쪽의 전송 조건이 맞아야 한다고 설명해요. 다만 특정 Intel 그래픽 환경을 다룬 자료이므로, 여기에 나온 단자 버전을 모든 모니터의 공통 기준으로 삼지는 마세요.

3. 허브가 있다면 연결 경로를 하나씩 확인해요

컴퓨터 → 허브나 변환 어댑터 → 케이블 → 모니터 순서로 현재 연결을 적어 보세요. 각 장치의 사양에서 지원 해상도와 주사율을 한 쌍으로 확인하면 어느 구간을 더 살펴야 하는지 정리하기 쉬워요.

이미 가지고 있는 호환 케이블과 단자로 직접 연결할 수 있다면, 중간 장치를 제외했을 때 목록이 달라지는지 비교해 보세요. 이는 원인을 좁히기 위한 비교이며, 직접 연결만으로 144Hz가 보장된다는 뜻은 아니에요. 확인을 위해 케이블부터 새로 살 필요는 없어요.

4. 지원 조건은 맞는데 목록이 없으면 정보를 모아요

모니터와 컴퓨터 모델명, 사용 중인 입력 단자, 해상도, Windows에 표시되는 주사율을 기록해요. 허브나 어댑터가 있다면 모델명도 함께 적어 두세요. 이 정보를 제조사에 전달하면 단자 지원 범위와 드라이버 점검 방향을 확인하는 데 도움이 돼요.

설명서가 지원하지 않는 주사율을 강제로 추가하는 방법은 이 글에서 다루지 않아요. 화면이 나온다는 사실만으로 목표 주사율까지 지원한다고 판단하지 마세요.

5. 부족한 연결 구간을 확인한 뒤 교체해요

케이블이나 허브의 지원 범위가 부족한 것으로 확인됐다면 목표 해상도와 144Hz를 함께 지원하는지 확인하고 교체하세요. 컴퓨터 출력 자체가 제한된다면 케이블만 바꿔도 해결되지 않을 수 있어요.

모니터 교체를 고려한다면 아래 비교글에서 해상도·크기·주사율을 함께 살펴보세요. 최대 주사율 숫자뿐 아니라 내 컴퓨터에 연결할 단자 조건도 구매 전에 확인하는 편이 좋아요.
