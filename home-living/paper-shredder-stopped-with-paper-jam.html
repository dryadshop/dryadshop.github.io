문서세단기가 종이를 물고 멈췄을 때 확인할 것

멈춘 세단기에 종이를 더 밀어 넣지 마세요. 종이 걸림 외에 과열이나 파지함 장착 상태도 확인해야 해요. 역회전은 해당 모델 설명서대로 조작하고, 손으로 종이를 빼거나 파지함을 정리할 때는 전원을 끄고 플러그를 뽑아야 해요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 17일

출처: Fellowes 코리아: Microshred 6M 한국어 설명서, 문제 해결·안전 안내, Fellowes: P-30C 영국판 설명서, 작동·냉각·종이 걸림 안내

점검 순서

  1. 1. 더 넣지 말고 표시와 사용 시간을 확인해요
  2. 2. 파지함을 비우고 헤드가 제대로 놓였는지 봐요
  3. 3. 역회전 조작과 종이 제거를 나눠 진행해요
  4. 다시 쓸 때는 매수와 허용 재질을 확인해요
  5. 빠지지 않거나 다시 멈추면 수리를 문의해요

1. 더 넣지 말고 표시와 사용 시간을 확인해요

종이를 여러 번 연속으로 넣은 뒤 멈췄다면 과열로 쉬는 중일 수 있어요. 표시등과 연속 사용 시간을 확인하고 설명서에 정해진 시간만큼 식혀 주세요. 냉각 시간을 모든 세단기에 똑같이 적용하면 안 돼요.

예를 들어 확인한 Fellowes 6M 한국어 설명서는 최대 5분 연속 사용과 30분 냉각을 안내해요. P-30C 영국판 설명서는 최대 3분 사용과 40분 냉각으로 달라요. 숫자를 외우기보다 사용하는 모델과 판매 지역의 설명서를 확인하는 게 먼저예요.

2. 파지함을 비우고 헤드가 제대로 놓였는지 봐요

스위치를 끄고 플러그를 뽑은 상태에서 파지함이 가득 찼는지 확인하세요. 비운 뒤에는 헤드나 파지함을 원래 위치에 정확히 놓아요. Fellowes 6M과 P-30C는 헤드가 파지함에 제대로 놓여 있어야 작동해요.

안전장치를 누르거나 고정해 억지로 작동시키지 마세요. 헤드 아래 노출된 칼날과 투입구 안쪽에도 손을 넣으면 안 돼요.

3. 역회전 조작과 종이 제거를 나눠 진행해요

제품이 손상되지 않았고 과열 대기가 끝났다면 해당 모델의 종이 걸림 절차를 확인하세요. 6M 설명서는 역방향 R로 2~3초 작동하고, 자동 작동과 역방향을 천천히 번갈아 사용하는 순서를 안내해요. 이때 투입구에서 손과 머리카락, 옷을 멀리 두세요.

손으로 남은 종이를 빼는 단계로 넘어갈 때는 먼저 OFF로 끄고 플러그를 뽑아요. 설명서가 허용하는 범위에서 위로 나온 종이를 천천히 빼되, 힘을 줘야 하거나 안쪽에 걸려 닿지 않으면 중단하세요. 다른 모델의 조작 시간과 스위치 위치는 따로 확인해야 해요.

다시 쓸 때는 매수와 허용 재질을 확인해요

최대 세단 매수에는 기준 종이의 두께와 사용 조건이 있어요. 두꺼운 종이를 표시 매수만큼 넣어도 된다는 뜻은 아니에요. 접착 라벨이나 코팅지, 클립처럼 넣을 수 있는지 헷갈리는 재질은 설명서에서 먼저 확인하세요.

유지보수용 오일이 필요한 제품도 있지만, 걸렸다는 이유로 아무 윤활제나 뿌리면 안 돼요. Fellowes는 에어로졸과 석유계 윤활유, 압축가스 먼지 제거제 사용을 금지해요. 오일은 해당 모델이 지정한 종류와 주입 방법을 따라야 해요.

빠지지 않거나 다시 멈추면 수리를 문의해요

설명서의 걸림 해소 절차로 빠지지 않는 종이를 무리하게 잡아당기거나 기기를 분해하지 마세요. 파손·이상이 있는 제품은 사용을 멈추고 고객지원에 문의하세요. 모델명, 넣은 재질과 매수, 표시등과 냉각 후 결과를 알려주면 상담에 도움이 돼요.

수리나 교체가 필요하다고 확인된 뒤에는 아래 문서세단기 비교글에서 평소 처리량과 파지함 크기를 살펴보세요. 같은 최대 매수라도 연속 작동 시간과 냉각 조건은 별도로 확인해야 해요.
