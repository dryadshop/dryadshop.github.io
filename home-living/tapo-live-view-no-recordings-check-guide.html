Tapo 홈캠 실시간 화면은 나오는데 녹화 영상이 없을 때

실시간 화면이 보이는 것과 지난 영상이 저장되는 것은 별개예요. 먼저 SD 카드에 저장한 영상을 찾는지 확인하고, 로컬 녹화와 해당 시간대의 녹화 일정을 살펴보세요. 감지할 때만 녹화하도록 되어 있다면 영상 사이에 빈 구간이 생길 수 있어요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 29일

출처: TP-Link: 연속 녹화 설정과 재생 방법 (2026-03-30, 확인 2026-10-29), TP-Link: 24시간 녹화와 홈·외출 모드 주의사항 (2024-06-30, 확인 2026-10-29), TP-Link: SD 카드 인식·포맷 문제 해결 (확인 2026-10-29)

점검 순서

  1. 1. 어떤 저장 공간의 영상을 찾는지 확인해요
  2. 2. 로컬 녹화와 카드 인식 상태를 봐요
  3. 3. 빈 구간의 녹화 일정을 확인해요
  4. 4. 연속 녹화 메뉴가 없는 모델도 있어요
  5. 설정이 맞는데도 저장되지 않으면 기록을 남겨요

1. 어떤 저장 공간의 영상을 찾는지 확인해요

이 글은 Tapo의 SD 카드·허브 로컬 녹화 점검을 다뤄요. 로컬 녹화는 집에 있는 카드나 허브에 영상을 저장하는 방식이에요. Tapo Care 클라우드 영상이나 휴대전화에 직접 저장한 영상과 구분해 주세요.

실시간 화면에서 ‘재생 및 다운로드’를 열고 SD 카드 항목과 날짜를 선택해 보세요. 시간 막대를 움직여 원하는 구간을 찾을 수 있어요. 앱 버전에 따라 메뉴 이름은 조금 다를 수 있어요.

2. 로컬 녹화와 카드 인식 상태를 봐요

카메라의 기기 설정에서 ‘스토리지 및 녹화’를 열고 로컬 녹화가 켜져 있는지 살펴보세요. 카드가 인식되는지와 표시되는 오류 문구도 함께 확인해요.

카드 오류가 보인다고 바로 포맷하지는 마세요. 포맷하면 저장된 영상이 삭제됩니다. 필요한 영상이 남아 있을 수 있으니 보존할 방법을 먼저 확인하고, 인식 불량은 TP-Link의 별도 카드 점검 안내를 따르세요.

3. 빈 구간의 녹화 일정을 확인해요

연속 녹화를 지원하는 모델에서는 일정에 연속 녹화, 감지 녹화, 녹화 없음이 어떻게 배치되어 있는지 확인해요. 감지 녹화는 움직임 등 설정한 사건이 감지됐을 때 저장하므로 하루 전체가 이어지지 않을 수 있어요.

감지 녹화를 쓰면서 감지 기능을 꺼 두지 않았는지도 봐주세요. 홈 모드·외출 모드를 적용했다면 녹화 설정이 바뀌었는지 다시 살펴요. 필요한 시간대를 수정했다면 저장 표시까지 눌러야 해요.

4. 연속 녹화 메뉴가 없는 모델도 있어요

TP-Link는 C400·C420·D230 등 배터리 구동 모델의 연속 녹화 제한을 안내해요. 메뉴가 없다고 카드를 교체하기 전에 정확한 모델의 지원 기능을 확인해 주세요.

설정을 바꾼 뒤 새로 녹화되는 구간이 생기는지 확인해요. 지금 녹화를 켠다고 저장되지 않았던 과거 영상이 생기는 것은 아니에요.

설정이 맞는데도 저장되지 않으면 기록을 남겨요

모델명, 앱·펌웨어 버전, 카드 상태, 녹화 일정과 영상이 비어 있는 시간을 정리해 고객지원에 전달해 보세요. 카드를 새로 사야 한다면 용량만 보지 말고 해당 카메라의 호환성 안내도 확인해요.

필요한 녹화 방식을 현재 모델이 지원하지 않아 교체를 검토한다면 아래 홈캠 비교글을 참고하세요. 설치 장소뿐 아니라 전원과 영상 저장 방식도 함께 고르는 것이 좋아요.
