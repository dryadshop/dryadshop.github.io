블루투스 마우스가 자꾸 끊길 때, 다시 연결하기 전에 볼 것

마우스가 끊길 때마다 다시 등록하기 전에, 사용 중에도 끊기는지 잠시 쉬었다 돌아왔을 때만 멈추는지 적어 보세요. 전원과 연결 모드, 컴퓨터와의 거리를 먼저 확인하고 Windows의 Bluetooth 점검으로 넘어가면 원인을 좁히기 쉬워요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 11일

출처: ASUS 공식지원 · Bluetooth 기능 이상 문제, Microsoft 지원 · Microsoft Bluetooth 마우스 사용

1. 끊기는 시점과 연결 방식을 적어 봐요

사용 중 갑자기 멈추는지, 컴퓨터가 잠든 뒤 다시 켰을 때만 멈추는지 구분해요. Windows의 Bluetooth 장치 목록에서 연결 상태도 함께 확인해 두세요. 커서가 멈춘 현상만으로 무선 연결이 끊겼다고 확정하지는 마세요.

USB 수신기와 Bluetooth를 모두 지원하는 마우스라면 지금 어느 방식으로 쓰는지 확인해요. 제품에 따라 연결할 컴퓨터나 모드를 고르는 버튼이 있으니 설명서의 표시와 맞춰 보세요.

2. 마우스 전원과 배터리부터 확인해요

마우스 전원을 껐다 켜고 충전이나 배터리 상태를 확인해요. 배터리 교체형인지 충전형인지에 따라 확인 방법은 달라요. Microsoft Bluetooth Mouse의 AA 배터리 안내를 모든 마우스에 적용할 수는 없어요.

다시 등록해야 한다면 다른 입력 수단을 사용할 수 있는 상태에서 진행하세요. 전원 버튼과 연결 대기 버튼이 같은 제품도 있지만, 누르는 시간은 모델별 설명서를 따라야 해요.

3. 가까운 자리에서 같은 증상이 생기는지 봐요

ASUS는 Bluetooth 연결 문제를 점검할 때 컴퓨터와 장치를 가까이 두고 사이를 가리는 물체를 줄이도록 안내해요. 책상 위 배치를 잠시 바꾼 뒤 같은 작업에서 다시 끊기는지 살펴보세요.

이미 다른 호환 컴퓨터나 이 마우스 전용 수신기가 있다면 연결 방식을 바꿨을 때도 문제가 생기는지 비교할 수 있어요. 이는 고장을 확정하는 시험이 아니라 어느 연결에서 문제가 반복되는지 알아보기 위한 확인이에요. 임의의 USB 수신기를 사서 연결하지는 마세요.

4. Windows와 제조사 드라이버를 점검해요

기본 확인 후에도 끊기면 Windows의 Bluetooth 문제 해결 도구와 PC 제조사의 드라이버 안내를 확인해요. ASUS PC는 공식 지원 페이지에서 해당 모델의 Bluetooth 드라이버와 업데이트 방법을 찾을 수 있어요.

절전 후에만 문제가 생겼다면 그 조건을 문의할 때 전달하세요. 모든 PC에서 전원 관리 항목이 같다고 가정해 설정을 한꺼번에 바꾸거나, 원인을 모른 채 장치를 연달아 삭제하는 방법은 권하지 않아요.

5. 마우스와 PC 중 어느 쪽을 점검할지 정해요

확인한 전원 상태, 끊기는 시점, 다른 연결에서의 결과를 정리해 제조사에 문의해요. 한 PC에서 여러 Bluetooth 장치가 함께 불안정한지, 이 마우스만 반복해서 멈추는지도 도움이 되는 정보예요.

교체가 필요하다고 확인되면 아래 무선 마우스 비교글에서 Bluetooth와 USB 수신기 중 내 PC에 맞는 방식을 살펴보세요. 지금 생긴 연결 문제가 새 마우스만으로 해결될지는 별도로 확인해야 해요.
