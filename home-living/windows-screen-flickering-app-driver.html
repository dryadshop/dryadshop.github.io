화면 깜빡임과 신호 끊김을 구분해요

창이나 화면이 반복해서 번쩍이는지, 모니터가 검게 변하며 신호 없음 표시가 뜨는지 먼저 기록해요. 이 글은 Windows 바탕화면을 볼 수 있는 상태에서 앱과 드라이버를 구분하는 안내예요.

신호 자체가 끊긴다면 외부 모니터의 전원과 영상 케이블 연결부터 확인해요. 갖고 있는 다른 케이블이나 모니터로 비교할 수 있다면 연결 쪽 문제를 좁히는 데 도움이 돼요.

1. 작업 관리자를 함께 띄워 보세요

Ctrl + Shift + Esc로 작업 관리자를 열고 원래 깜빡이던 화면과 비교해요. Microsoft는 작업 관리자까지 함께 깜빡이면 디스플레이 드라이버를, 나머지 화면만 깜빡이면 호환되지 않는 앱을 우선 살펴보도록 안내해요.

항상 어느 한쪽이 원인이라는 뜻은 아니에요. 깜빡임이 나타난 앱 이름과 시작 시점도 함께 기록하세요.

2. 드라이버 쪽이라면 업데이트 시점을 확인해요

드라이버는 Windows가 그래픽 장치를 제어하는 소프트웨어예요. Windows + Ctrl + Shift + B로 그래픽 드라이버를 재설정하거나 PC를 다시 시작한 뒤 증상이 남는지 확인할 수 있어요.

업데이트 직후 시작됐다면 장치 관리자의 디스플레이 어댑터에서 해당 장치의 속성 → 드라이버 → 드라이버 롤백을 살펴봐요. 롤백은 이전 버전으로 되돌리는 기능이며, 관리자 권한이 필요하고 이전 드라이버가 없으면 사용할 수 없어요. 그 외에는 PC나 그래픽 장치 제조사가 제공하는 업데이트를 확인해요.

3. 특정 앱 쪽이라면 그 앱부터 확인해요

Microsoft Store 앱은 Store에서, 다른 앱은 개발사 공식 사이트에서 업데이트를 확인해요. 업데이트 후에도 같은 앱에서만 반복된다면 해당 앱 지원 안내를 살펴보세요. 삭제를 검토할 때는 저장 데이터와 재설치 방법을 먼저 확인해요.

모니터를 새로 사기 전에

바꾼 설정이나 드라이버 버전과 증상 변화를 기록해 두세요. 화면을 읽기 어려울 정도라면 무작정 여러 항목을 변경하지 말고 PC 제조사 지원을 받아요. 연결과 소프트웨어 점검만으로 화면 패널의 정상 여부까지 확정할 수는 없어요.

교체가 필요하다는 점검을 받은 뒤에는 관련 모니터 비교글에서 해상도와 연결 조건을 살펴보세요. 이 글의 메뉴와 키 조합은 Windows 기준이며 macOS에는 그대로 적용되지 않아요.
