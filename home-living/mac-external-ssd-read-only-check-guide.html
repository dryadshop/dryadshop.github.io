맥에서 외장 SSD 파일은 열리는데 저장·삭제가 안 될 때

파일이 보인다고 맥에서 수정까지 가능한 것은 아니에요. Windows에서 쓰던 SSD라면 먼저 NTFS 형식인지 확인해 보세요. 저장 공간이나 권한 문제일 수도 있으니, 바로 포맷하지 말고 오류 문구와 현재 형식부터 살펴요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 29일

출처: Apple: Mac에서 외장 드라이브에 파일을 저장할 수 없는 경우 (2025-12-11, 확인 2026-10-29)

점검 순서

  1. 1. 읽기와 쓰기 중 어디에서 막히는지 봐요
  2. 2. ‘정보 가져오기’에서 형식을 확인해요
  3. 3. NTFS가 아니라면 권한과 백업 용도를 살펴요
  4. 4. 형식을 바꾸기 전에는 백업이 먼저예요
  5. 파일을 읽는 데도 문제가 생기면 점검을 받아요

1. 읽기와 쓰기 중 어디에서 막히는지 봐요

SSD 안의 파일을 열 수 있는지, 맥으로 복사할 수 있는지 먼저 확인해요. 반대로 SSD에 파일을 넣거나 이름을 바꿀 때만 실패한다면 쓰기 쪽 문제를 살펴볼 차례예요.

파일 하나만 실패하는지, 다른 폴더에서도 같은지와 오류 문구를 적어 두세요. 공간 부족 안내가 나온다면 여유 용량도 함께 확인해요. 필요한 자료부터 지워 공간을 만들지는 마세요.

2. ‘정보 가져오기’에서 형식을 확인해요

Finder에서 외장 SSD를 선택하고 command-I를 누르면 정보 창이 열려요. ‘포맷’에 NTFS라고 표시되는지 봐주세요. 맥은 기본적으로 NTFS 드라이브의 파일을 읽을 수 있지만 쓰기는 지원하지 않아요.

이 경우 더 빠른 케이블이나 새 SSD를 사는 것만으로 해결되지는 않아요. 별도 쓰기 지원 프로그램을 쓰고 있다면 해당 프로그램의 macOS 호환성과 상태도 따로 확인해야 해요.

3. NTFS가 아니라면 권한과 백업 용도를 살펴요

같은 정보 창의 ‘공유 및 사용 권한’도 확인해 보세요. Apple은 해당 항목이 표시되는 경우 ‘이 볼륨에서 소유권 무시’ 설정을 확인하도록 안내해요. 회사나 다른 사람이 관리하는 디스크의 권한을 임의로 바꾸지는 마세요.

Time Machine 백업 대상으로 쓰는 저장 공간인지도 살펴봐요. 백업용으로 설정된 공간을 일반 파일 저장 공간처럼 쓰려는 상황이라면, 기존 백업을 지우기 전에 용도부터 정해야 해요.

4. 형식을 바꾸기 전에는 백업이 먼저예요

포맷하면 대상 저장 공간의 데이터가 삭제됩니다. 다른 저장장치에 복사한 파일이 실제로 열리는지 확인하기 전에는 ‘지우기’를 실행하지 마세요.

Mac과 Windows를 오가며 쓸지, 맥에서만 쓸지에 따라 필요한 형식이 달라져요. 형식을 바꾸기로 했다면 연결할 기기의 지원 조건을 확인하고 Apple의 디스크 유틸리티 안내를 따르세요.

파일을 읽는 데도 문제가 생기면 점검을 받아요

기존 파일까지 열리지 않거나 연결이 반복해서 끊긴다면 읽기 전용 문제로만 보기는 어려워요. 필요한 자료의 보존을 우선하고, 오류 문구와 SSD 모델을 제조사에 전달하세요. 복구되지 않는 디스크를 반복해서 지우지는 마세요.

용량이나 연결 단자 때문에 교체가 필요할 때는 아래 외장 SSD 비교글을 참고할 수 있어요. 새 제품도 사용하는 운영체제와 파일시스템이 맞는지 확인해 주세요.
