키보드 오른쪽 숫자패드만 입력되지 않을 때

문자는 입력되는데 오른쪽 숫자패드만 작동하지 않는다면 Num Lock과 Windows의 마우스 키 설정부터 살펴보세요. 마우스 키는 숫자패드로 포인터를 움직이는 기능이에요. 숫자패드 전체가 안 되는지, 특정 키만 안 되는지도 구분해요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 11월 1일

출처: LG전자 — 키보드의 숫자키 입력이 안 돼요, Microsoft — 마우스·키보드와 입력 장치 접근성 설정

점검 순서

  1. 1. Num Lock을 켠 뒤 메모장에서 입력해요
  2. 2. 숫자 대신 포인터가 움직인다면
  3. 3. 특정 앱인지, 특정 키인지 확인해요
  4. 급한 숫자 입력은 다른 방법으로 이어가요
  5. 새 키보드나 숫자패드를 사기 전에는

1. Num Lock을 켠 뒤 메모장에서 입력해요

숫자패드의 Num Lock 또는 NumLk 키를 확인해요. 숫자 입력 상태로 바꾼 뒤 메모장을 열어 테스트하세요. 키 위치나 Fn 조합은 제품마다 다르므로 키보드 안내를 따라요.

LG는 상태 알림이 화면에 뜨지 않더라도 기능은 작동할 수 있다고 설명해요. 표시가 없다는 이유로 고장으로 판단하지 말고 실제로 숫자가 입력되는지 보세요.

2. 숫자 대신 포인터가 움직인다면

Windows 검색에서 마우스 키를 찾아 설정을 열어요. 숫자패드를 포인터 제어에 쓸 필요가 없다면 마우스 키를 끄고 다시 입력해 보세요. 접근성 기능으로 평소 사용하던 설정이라면 바꾸기 전에 기존 상태를 기록해 두는 편이 좋아요.

이 안내는 Windows 기준이에요. 키보드에 숫자패드가 없는 경우나 macOS를 사용하는 경우에는 같은 키 조합과 메뉴를 그대로 적용하지 않아요.

3. 특정 앱인지, 특정 키인지 확인해요

메모장에서는 되는데 엑셀 등 특정 앱에서만 안 된다면 그 앱에서 입력하려는 칸과 단축키 설정을 살펴볼 차례예요. 반대로 어느 입력창에서도 같은 숫자 하나만 반응하지 않는다면 숫자패드 전체 설정과는 다른 문제일 수 있어요.

작동하지 않는 키와 테스트한 앱을 적어 두세요. LG 안내도 일부 키만 눌리지 않는 경우에는 하드웨어 점검이 필요할 수 있다고 설명해요. 이 결과만으로 모든 키보드의 고장 부위를 확정하지는 않아요.

급한 숫자 입력은 다른 방법으로 이어가요

윗줄 숫자 키가 정상이라면 우선 그쪽을 사용할 수 있어요. Windows의 설정 → 접근성 → 키보드에서 화상 키보드를 켜는 방법도 있어요. 화면에 나타난 키를 마우스로 눌러 급한 입력을 이어갈 수 있어요.

새 키보드나 숫자패드를 사기 전에는

Num Lock과 마우스 키 설정을 확인해도 같은 키가 계속 반응하지 않으면 제조사에 모델명과 증상을 전달해 점검받으세요. 설정을 바꾸니 정상 입력된다면 이 증상 때문에 별도 숫자패드를 살 필요는 없어요.

교체가 필요해졌다면 관련 기계식 키보드 비교글에서 숫자패드가 있는 풀배열과 없는 배열의 차이를 살펴보세요. 책상 공간뿐 아니라 평소 숫자를 입력하는 양도 함께 생각해요.
