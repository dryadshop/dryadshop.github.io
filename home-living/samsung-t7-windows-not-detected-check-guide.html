삼성 T7 외장 SSD가 윈도우에 안 뜰 때, 포맷 전에 확인할 것

기존 파일이 들어 있다면 초기화나 포맷 안내에서 먼저 취소를 누르세요. T7을 허브에서 빼서 PC에 직접 연결한 뒤, 파일 탐색기에 없어도 디스크 관리에는 표시되는지 살펴보세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

1. 허브를 빼고 PC에 직접 연결해요

T7에 들어 있던 케이블처럼 데이터를 전송할 수 있는 케이블을 써 보세요. PC 본체에 바로 연결하고, 반응이 없으면 가지고 있는 다른 USB 포트로 바꿔요.

다른 데이터 케이블이나 PC가 있다면 하나씩 바꿔 보세요. 특정 포트에서만 안 되는지, 다른 PC에서도 안 보이는지 알면 문의할 때 설명하기 쉬워요.

2. 파일 탐색기에서 안 보이면 디스크 관리를 열어요

윈도우에서 컴퓨터 관리를 열고 저장소의 디스크 관리로 들어가세요. T7을 연결하기 전과 후의 목록을 비교하면 새로 나타나는 항목을 찾기 쉬워요. 용량도 대조해 다른 디스크와 혼동하지 마세요.

디스크 관리에도 새 항목이 없으면 윈도우가 저장장치로 표시하지 못한 상태예요. T7이 보인다면 드라이브 문자, 파일 시스템과 상태를 확인하세요.

3. 상태에 따라 다음 행동을 골라요

파티션이 정상으로 표시되고 윈도우에서 읽을 수 있는 파일 시스템이 있는데 드라이브 문자만 비어 있다면, Microsoft 안내에 따라 문자를 추가할 수 있어요.

파일이 있던 디스크가 RAW, 할당되지 않음, 초기화되지 않음으로 표시되면 상태 화면을 기록해 두세요. 파일을 살려야 한다면 초기화, 포맷, 새 볼륨 만들기는 진행하지 마세요.

파일을 읽을 수 있게 되면 먼저 백업해요

다른 포트나 PC에서 파일이 열리면 중요한 파일부터 다른 저장장치에 복사하세요. 여러 포트와 PC에서 계속 안 보이면 삼성 저장장치 지원에 문의하고, 중요한 자료의 백업이 없다면 복구 가능 여부를 먼저 상담하세요.
