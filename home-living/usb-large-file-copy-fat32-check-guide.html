USB에 공간이 남았는데 큰 파일을 복사할 수 없을 때

남은 공간이 충분한데 특정 큰 파일만 복사되지 않는다면 USB의 파일시스템을 확인해 보세요. FAT32는 파일 하나를 약 4GB까지만 저장할 수 있어요. USB 전체 용량이 커도 이 제한은 남기 때문에, 더 큰 USB를 사는 것만으로 해결되지는 않아요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

출처: Microsoft Learn: 파일시스템별 기능과 크기 제한, SanDisk: 파일이 너무 크다는 오류와 파일시스템 선택, Microsoft: 디스크 관리와 포맷 전 주의사항

1. 전체 용량과 파일 하나의 크기를 나눠 봐요

먼저 오류 문구를 확인해 보세요. 파일이 대상 파일시스템에 비해 너무 크다는 안내와 실제 저장 공간 부족은 같은 문제가 아니에요. 옮기려는 파일 하나의 크기, 파일 전체의 합계와 USB 여유 공간을 각각 확인해 주세요.

예를 들어 빈 공간이 20GB인 FAT32 USB에도 6GB 영상 한 개는 그대로 담을 수 없어요. 폴더 안 파일의 합계만 보지 말고, 그중 가장 큰 파일을 찾아보는 이유예요.

2. 포맷을 누르지 않고 현재 형식을 확인해요

파일시스템은 저장장치가 파일을 기록하고 관리하는 방식이에요. Windows 파일 탐색기의 내 PC에서 USB 드라이브를 마우스 오른쪽 버튼으로 누르고 속성을 열면 현재 파일시스템을 확인할 수 있어요. 이 단계에서는 포맷할 필요가 없어요.

FAT32라면 큰 파일의 저장 제한과 맞는 증상인지 대조해 보세요. 이미 exFAT나 NTFS라면 FAT32 제한을 원인으로 단정하지 말고, 실제 여유 공간과 오류 문구를 다시 확인해야 해요.

3. USB를 꽂을 기기가 어떤 형식을 지원하는지 봐요

Windows와 Mac 사이에서 큰 파일을 옮긴다면 exFAT가 선택지가 될 수 있어요. NTFS는 Windows에서 읽고 쓸 수 있지만, Mac에서는 별도 드라이버가 없으면 일반적으로 읽기만 가능해요.

TV나 차량, 구형 기기에 꽂을 USB라면 그 기기의 설명서부터 확인해 주세요. 컴퓨터에서 복사가 된다고 대상 기기에서도 읽을 수 있는 것은 아니에요. 파일시스템뿐 아니라 영상 파일 형식 등 재생 조건도 따로 살펴봐야 해요.

4. 형식을 바꿔야 한다면 백업이 먼저예요

포맷하면 USB에 저장된 데이터가 삭제됩니다. 빠른 포맷도 기존 파일을 보존하는 방법이 아니에요. 필요한 파일을 다른 저장장치에 복사하고, 백업한 파일이 실제로 열리는지 확인한 뒤 진행해야 해요.

백업과 호환성 확인이 끝났을 때만 운영체제나 저장장치 제조사의 공식 포맷 안내를 따라 주세요. 대상 드라이브의 이름과 용량을 다시 확인해 다른 디스크를 선택하지 않도록 주의해요. 포맷 뒤에는 원본을 지우기 전에 복사한 파일을 대상 기기에서 열어 보세요.

새 USB가 필요한지는 따로 판단해요

파일 크기 제한 때문에 생긴 문제라면 저장장치를 교체하기 전에 형식과 사용 목적부터 맞추면 돼요. 반면 작은 파일도 실패하거나 연결이 끊기고 기존 파일을 읽지 못한다면 반복 포맷보다 원본 보존과 제조사 상담을 먼저 생각해 주세요.

저장 공간이나 단자 때문에 교체가 필요한 경우에는 아래 USB 메모리 비교 글에서 USB-A·USB-C와 필요한 용량을 살펴볼 수 있어요. 새 제품도 사용 전 파일시스템과 연결 기기 지원 조건을 확인해 주세요.
