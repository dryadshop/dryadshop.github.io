가습기를 계속 켜도 습도가 안 오를 때 확인할 것

습도 숫자가 그대로라고 바로 고장은 아니에요. 가습할 공간이 너무 넓거나 문이 열려 있을 수 있고, 목표 습도에 도달해 작동을 멈춘 경우도 있어요. 방의 조건과 설정을 먼저 확인한 뒤, 기화식이라면 필터 조립과 관리 상태를 살펴보세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

미스트가 안 보이는 것과 습도가 안 오르는 것은 달라요

기화식은 물을 머금은 필터에서 수분이 증발하는 방식이라 눈에 보이는 미스트가 없어도 작동할 수 있어요. 미스트 유무만 보고 분무 고장으로 판단하지 마세요.

먼저 모델명, 사용 중인 모드, 목표 습도와 현재 표시를 적어 보세요. 아래 필터 점검은 필터를 쓰는 기화식에 해당해요. 초음파식 진동자나 가열식 가열부에 같은 청소법을 적용하면 안 돼요.

1. 지금 가습하는 공간이 얼마나 넓은지 보세요

방문을 열어 두면 침실뿐 아니라 이어진 거실까지 가습하게 될 수 있어요. 필요한 환기를 마친 뒤 문과 창문을 닫은 상태에서 표시 변화를 확인해 보세요. 제품 설명서의 권장 사용면적과 실제 공간도 대조해요.

새 가구가 들어온 방은 가구가 수분을 흡수해 원하는 습도에 도달하는 데 시간이 더 걸릴 수 있다고 필립스는 안내해요. 다만 모든 방이 몇 분 안에 특정 습도에 도달한다고 정해 둘 수는 없어요.

2. 목표 습도에 도달해 멈춘 상태인지 확인해요

자동 모드에서는 설정한 습도에 도달하면 가습을 멈추는 제품이 있어요. 전원이 켜져 있다는 것과 계속 가습한다는 것은 달라요. 현재 습도와 목표값을 비교하고 해당 모델의 자동 운전 설명을 읽어 보세요.

다른 모델의 정지 기준이나 표시 갱신 시간을 그대로 적용하지 마세요. 숫자를 올리려고 목표값만 계속 높이기보다 지금 어떤 조건에서 작동을 멈추는지 먼저 구분하는 편이 좋아요.

3. 기화식은 필터 조립과 오염 상태를 살펴보세요

필터가 지지대에 제대로 끼워져 있는지, 물때나 오염이 쌓여 있지 않은지 확인해요. 필립스는 필터의 잘못된 조립과 오염을 가습이 잘되지 않는 원인으로 안내하고 있어요.

청소는 전원을 끄고 플러그를 뺀 뒤 해당 모델의 설명서대로 진행하세요. 세척 가능한 부품과 허용 세정제는 제품마다 달라요. 다른 가습기의 식초·구연산 농도나 담금 시간을 가져와 적용하지 마세요.

4. 같은 조건에서 다시 확인한 뒤 상담해요

설정이나 설치 조건을 바꿀 때마다 무엇을 바꿨는지 기록해 두세요. 그래야 청소 뒤에도 같은 문제인지, 문을 열었을 때만 달라지는지 구분하기 쉬워요.

설명서에 맞게 조립·관리했는데도 변화가 없다면 모델명과 사용 모드, 방 크기, 시도한 점검을 정리해 제조사에 문의하세요. 필터는 해당 모델의 교체 기준에 맞을 때 바꾸고, 공간이 권장 범위를 벗어날 때에만 다른 용량이나 추가 제품을 검토해요.
