휴대폰을 바꾼 뒤 소니 WH-1000XM4가 연결되지 않을 때

새 휴대폰에는 헤드폰을 다시 등록하는 페어링이 필요해요. WH-1000XM4의 전원을 켜는 것만으로 등록 모드에 들어갔다고 볼 수는 없어요. 먼저 이전 기기와의 연결을 끊고 페어링 모드를 확인하세요. 모든 등록 정보가 지워지는 공장 초기화부터 할 필요는 없어요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

1. 이전 휴대폰이나 컴퓨터의 연결을 확인해요

소니는 마지막으로 사용한 기기에 자동 연결되어 새 기기 연결이 어려울 수 있다고 안내해요. 기존 기기에서 헤드폰의 Bluetooth 연결을 해제한 뒤 새 휴대폰의 Bluetooth가 켜져 있는지 보세요. 이 글의 버튼 조작은 WH-1000XM4 기준이에요. WF-1000XM4 이어폰이나 다른 헤드폰에는 해당 모델 안내를 따르세요.

2. 전원 버튼을 누른 뒤 페어링 안내를 기다려요

헤드폰을 충분히 충전하고 휴대폰을 가까이 둬요. 이미 다른 기기를 등록한 WH-1000XM4는 전원 버튼을 약 7초 동안 눌러 페어링 모드에 들어가요. 파란 표시등이 두 번씩 반복해서 깜빡이고 Bluetooth pairing 안내가 나오는지 확인하세요.

3. iPhone에서는 Bluetooth 설정에서 이름을 골라요

iPhone의 설정 → Bluetooth에서 WH-1000XM4를 선택해요. LE_WH-1000XM4가 먼저 보이더라도 WH-1000XM4가 나타날 때까지 기다리세요. 공식 안내는 이름이 나타나기까지 약 30초~1분 걸릴 수 있다고 설명해요. Android의 화면과 등록 순서는 해당 휴대폰 안내를 함께 확인하세요.

4. 휴대폰을 재시작한 뒤 다시 등록해 보세요

연결되지 않으면 휴대폰을 재시작하고 페어링 모드부터 다시 확인해요. 소니는 휴대폰이나 컴퓨터를 재시작하면 연결 상태가 개선될 수 있다고 안내해요. 앱을 반복해서 삭제하기보다 헤드폰 이름이 Bluetooth 목록에 나타나는지부터 살펴보세요.

재설정과 공장 초기화는 달라요

WH-1000XM4의 재설정은 페어링 정보를 지우지 않지만, 공장 초기화는 모든 페어링 정보와 설정을 지워요. 소니는 재설정 후에도 정상 작동하지 않을 때 초기화를 안내해요. 필요한 경우 아래 공식 절차를 읽고 진행하세요. 초기화 뒤에는 휴대폰에 남은 헤드폰 등록도 삭제하고 다시 페어링해야 해요.

초기화까지 마쳤는데도 작동하지 않으면 소니에 점검을 요청하세요. 휴대폰 기종과 연결 목록, 시도한 절차를 정리해 두면 좋아요. 수리 상담 후 교체가 필요하다면 아래 헤드폰 비교글에서 무게와 배터리 조건을 살펴보세요.
