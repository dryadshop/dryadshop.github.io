스팀에서 게임패드 버튼이 두 번씩 입력될 때

먼저 Steam이 패드를 두 대로 표시하는지, 한 게임에서만 입력이 반복되는지 나눠 보세요. 장치가 중복으로 보이면 Steam 업데이트부터, 특정 게임에서만 생기면 버튼 배치와 입력 설정부터 확인해요. 같은 증상이라도 패드 고장과 설정 충돌을 바로 구분할 수는 없어요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 25일

출처: Valve: 2026년 10월 13일 Steam 클라이언트 업데이트, Steamworks: Steam Input 게임패드 에뮬레이션, Steam 지원: Steam Controller의 입력 충돌 점검, KOEI TECMO: 자사 Steam 게임의 컨트롤러 오작동 점검

점검 순서

  1. 1. 패드 한 대가 목록에도 한 대인지 보세요
  2. 2. Xbox 계열 패드가 두 대로 보이면 Steam을 업데이트해요
  3. 3. 다른 패드와 입력 변환 프로그램을 잠시 분리해요
  4. 4. 한 게임에서만 생기면 버튼 배치와 Steam Input을 봐요
  5. 5. 설정 점검 후에도 반복되면 문의할 정보를 모아요

1. 패드 한 대가 목록에도 한 대인지 보세요

게임을 종료하고 Steam의 ‘설정 → 컨트롤러’에서 장치 이름과 개수를 확인해요. 이어 입력 테스트를 열어 버튼을 짧게 한 번 눌렀을 때 어떤 반응이 나오는지 보세요. 같은 동작을 다른 게임에서도 비교하면 특정 게임의 설정부터 볼지 판단하는 데 도움이 돼요.

이 글은 Windows PC에서 Steam을 사용하는 경우를 중심으로 정리했어요. 입력 테스트 화면이 정상이라는 이유만으로 모든 기기 문제가 배제되는 것은 아니에요. 패드 이름, 유선·무선 연결 방식, 문제가 생기는 게임을 함께 적어 두세요.

2. Xbox 계열 패드가 두 대로 보이면 Steam을 업데이트해요

Valve는 2026년 10월 13일 Steam 클라이언트 업데이트에서 Windows의 Xbox 계열 컨트롤러가 중복으로 표시되는 문제를 수정했다고 밝혔어요. 오래된 클라이언트라면 ‘Steam → Steam 클라이언트 업데이트 확인’을 실행하고 재시작한 뒤 목록을 다시 보세요.

이 수정이 모든 중복 입력의 해결책이라는 뜻은 아니에요. 최신 버전에서도 반복되면 다음 단계로 원인을 좁혀요. 오래된 해결 글을 따라 Windows 구성 요소나 드라이버부터 삭제하지 않아도 할 수 있는 점검이에요.

3. 다른 패드와 입력 변환 프로그램을 잠시 분리해요

연결한 다른 게임패드를 빼고 사용할 패드 하나만 남겨 보세요. 별도로 실행한 가상 패드나 버튼 재지정 프로그램이 있다면 종료한 뒤 Steam과 게임을 다시 시작해요. 가상 패드는 실제 패드의 입력을 다른 장치 입력으로 바꿔 전달하는 프로그램이에요.

Valve의 Steam Controller 지원 안내와 코에이테크모의 Steam 게임 지원 안내는 다른 입력 장치나 타사 프로그램의 충돌 가능성을 설명해요. 특정 프로그램이 반드시 원인이라는 뜻은 아니므로, 하나씩 바꾸고 변화가 없으면 원래 상태로 돌려놓아요.

4. 한 게임에서만 생기면 버튼 배치와 Steam Input을 봐요

Steam Input은 패드 입력을 게임이 알아들을 수 있는 형태로 바꿔 주는 기능이에요. 게임이 직접 지원하는 패드와 Steam Input이 필요한 패드는 설정이 다를 수 있어요. 게임 안의 버튼 배치와 Steam 컨트롤러 레이아웃을 먼저 확인하세요.

코에이테크모는 자사 Steam 게임의 컨트롤러 문제 점검으로 ‘라이브러리에서 게임 우클릭 → 속성 → 컨트롤러 → Steam Input 사용 안 함’을 안내해요. 해당 게임·패드가 자체 입력을 지원하는지 확인한 뒤 게임을 종료한 상태에서 시험해 보세요. 입력이 아예 사라지거나 개선되지 않으면 이전 설정으로 복원해요. 모든 게임에 일괄 적용할 설정은 아니에요.

5. 설정 점검 후에도 반복되면 문의할 정보를 모아요

유선 연결을 지원하는 패드라면 데이터 통신이 가능한 케이블과 다른 USB 포트로도 비교해 보세요. 한 게임에서만 재현되면 게임 지원팀에, 여러 환경에서 같은 버튼이 반복되면 패드 제조사에 문의할 근거가 돼요. 어느 경우든 기록만으로 고장 부위를 확정하지는 않아요.

문의할 때는 Steam 버전, 패드 모델, 장치 목록, 입력 테스트와 게임 안에서의 차이를 함께 전달하세요. 교체를 권고받았거나 기기 호환성 때문에 새 패드가 필요할 때 아래 비교글에서 PC 지원과 연결 방식을 살펴보세요.
