에어팟 한쪽 배터리만 빨리 줄어들 때, 교체 전에 확인할 것

한쪽이 먼저 꺼졌다면 처음부터 덜 충전됐는지, 같은 시간 사용한 뒤 더 많이 줄었는지부터 구분해 보세요. 좌우 잔량이 다르다는 사실만으로 배터리 불량이나 정상 여부를 확정할 수는 없어요. 교체를 결정하기 전에 충전 상태와 사용 조건을 기록해 두면 도움이 돼요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 29일

출처: Apple: AirPods 충전과 최적화된 충전 (2026-10-16, 확인 2026-10-29), Apple: AirPods이 충전되지 않는 경우 (2025-09-26, 확인 2026-10-29)

점검 순서

  1. 1. 케이스 잔량과 이어폰 잔량을 따로 봐요
  2. 2. 충전이 덜 된 쪽이 있다면 충전부터 확인해요
  3. 3. 100%가 아니라면 충전 최적화 설정도 살펴요
  4. 4. 같은 조건에서 사용한 기록을 남겨요
  5. 같은 쪽이 반복해서 먼저 꺼지면 상담해요

1. 케이스 잔량과 이어폰 잔량을 따로 봐요

케이스 표시등만 보고 양쪽 이어폰이 똑같이 충전됐다고 판단하지 마세요. Apple은 이어폰이 케이스 안에 있는지에 따라 표시등이 가리키는 대상이 달라진다고 안내해요.

덮개를 열거나 이어폰을 꺼낸 뒤 iPhone·iPad의 Bluetooth 설정에서 AirPods 정보를 확인해 보세요. 좌우 잔량이 따로 보일 때 사용 전 수치를 적고, 사용을 마친 시간과 잔량도 남겨요.

2. 충전이 덜 된 쪽이 있다면 충전부터 확인해요

처음부터 한쪽 잔량이 낮다면 사용 중 소모량을 비교하기 전에 충전 문제부터 살펴야 해요. 케이스와 케이블, 전원 연결 상태를 확인해 주세요.

AirPods·AirPods Pro가 충전되지 않을 때 Apple은 양쪽을 케이스에 넣고 덮개를 닫아 호환 케이블로 15분 이상 충전하도록 안내해요. 이후 잔량을 다시 보세요. 무선 충전이 불안정하다면 지원되는 케이블로 확인할 수 있어요. 이 안내를 AirPods Max에 그대로 적용하지는 마세요.

3. 100%가 아니라면 충전 최적화 설정도 살펴요

AirPods Pro와 AirPods 3 및 이후 모델은 사용 습관에 맞춰 완충 시점을 늦추는 최적화된 배터리 충전을 지원해요. AirPods Pro 3에는 최적화된 충전 한도도 있어요. 해당 기능의 유무는 정확한 모델과 소프트웨어에 따라 확인해 주세요.

충전량이 100%가 아니라는 이유만으로 고장이라고 볼 수는 없어요. 다만 이 기능이 켜져 있다는 사실만으로 좌우 차이의 원인이 확인된 것도 아니에요. 배터리 설정을 기록하고 충전 상태와 함께 살펴보세요.

4. 같은 조건에서 사용한 기록을 남겨요

양쪽의 시작 잔량을 확인한 뒤 같은 시간 동안 사용해 보세요. 음악을 들었는지 통화했는지, 한쪽만 따로 쓴 시간이 있었는지, 어느 쪽이 먼저 꺼졌는지도 함께 적어요.

이 기록은 원인을 확정하는 성능 시험이 아니라 상담 자료예요. ‘몇 퍼센트 차이면 정상’이라는 임의의 기준을 정하거나, 기록 한 번으로 배터리 수명을 계산하지 마세요.

같은 쪽이 반복해서 먼저 꺼지면 상담해요

충전이 되지 않는 증상이 남으면 해당 모델의 Apple 청소·재설정 안내를 확인해요. 재설정은 사용자 설정도 바꿀 수 있으니 현재 설정을 남긴 뒤 진행하세요. 세대별 절차를 한 가지 버튼 조작으로 통일하지 마세요.

사용시간 차이가 반복되면 모델명과 충전 전후 기록을 Apple 지원에 전달하고 점검을 받아요. 교체 비용과 방법은 점검 결과를 확인한 뒤 결정하면 돼요. 새 이어폰을 검토할 때는 아래 비교글에서 착용 방식과 충전 조건을 살펴볼 수 있어요.
