블루투스 스피커는 연결됐는데 소리가 안 날 때

연결됨 표시만으로 그 스피커에 소리가 나오도록 선택됐다는 뜻은 아니에요. 재생이 멈춰 있지 않은지, 출력 장치가 맞는지, 휴대전화·PC와 스피커 양쪽 볼륨이 낮지 않은지부터 확인해 보세요.

제조사·공공기관 안내를 바탕으로 정리한 조사형 안내입니다. 직접 사용하거나 같은 조건에서 시험한 후기가 아닙니다.

작성·검수: DShop 편집팀 · 최종 확인: 2026년 10월 14일

출처: Sony SRS-XB100: 소리가 나지 않을 때의 재생·볼륨 점검, Microsoft: Windows에서 Bluetooth 연결 후 소리가 나지 않는 문제 해결

점검 순서

  1. 1. 재생 상태와 양쪽 볼륨을 확인하세요
  2. 2. Windows에서는 출력 장치를 직접 골라요
  3. 3. 출력이 맞으면 연결을 다시 확인해요
  4. 4. 다른 기기에서는 들리는지 나눠 봐요
  5. 구매보다 먼저 점검 결과를 전달해요

1. 재생 상태와 양쪽 볼륨을 확인하세요

음악이나 영상의 재생 시간이 움직이는지 보고, 소리를 내보내는 기기와 스피커가 모두 켜져 있는지 확인해요. 소니 SRS-XB100 안내는 연결 기기와 스피커의 볼륨이 따로 조절될 수 있다고 설명해요.

소리가 없다고 두 기기의 볼륨을 처음부터 최대로 올리지 마세요. 연결이 복구되면 갑자기 큰 소리가 날 수 있으니 낮은 수준에서 조금씩 조절해요.

2. Windows에서는 출력 장치를 직접 골라요

Windows 11에서는 설정 → 시스템 → 사운드의 출력에서 사용하려는 Bluetooth 스피커를 선택하세요. Microsoft는 Bluetooth 연결 후 소리가 없을 때 출력 장치와 볼륨을 먼저 확인하도록 안내해요.

여기서 설명한 경로는 Windows 기준이에요. 휴대전화에서는 해당 기기의 오디오 출력 선택 화면을 확인하고, 메뉴 위치가 다르면 OS와 제조사 안내를 참고하세요. 다른 장치로 소리가 나오고 있지 않은지 보는 단계예요.

3. 출력이 맞으면 연결을 다시 확인해요

Windows에서는 Bluetooth를 껐다 켜거나 PC를 다시 시작한 뒤 재생해 보세요. 작업 중인 내용은 먼저 저장하고, 무선 키보드·마우스도 함께 끊길 수 있다는 점을 확인해요.

장치가 목록에만 있고 실제 연결이 되지 않는다면 해당 스피커를 제거한 뒤 다시 페어링하는 방법을 검토해요. 페어링은 기기를 서로 등록하는 과정이에요. 등록을 지우기 전 스피커 설명서의 연결 방법을 확인하고, 공장 초기화부터 하지는 마세요.

4. 다른 기기에서는 들리는지 나눠 봐요

가능하다면 다른 휴대전화나 PC에 같은 스피커를 연결해 재생해 보세요. 한 기기에서만 소리가 없다면 그 기기의 출력 설정과 지원 안내부터 확인할 수 있어요. 이 결과만으로 스피커 고장이 없다고 확정할 수는 없어요.

Windows 11에서 문제가 계속되면 Microsoft의 Bluetooth 문제 해결사와 PC 제조사의 드라이버 안내를 확인하세요. 출처를 알 수 없는 드라이버 설치 프로그램은 사용하지 마세요.

구매보다 먼저 점검 결과를 전달해요

다른 기기에서도 소리가 없거나 연결 자체가 유지되지 않으면 스피커 모델명, 연결한 기기와 OS, 시도한 점검을 제조사에 알려 주세요. 연결됨 표시만 보고 어댑터나 스피커를 바로 구입할 필요는 없어요.

수리 상담 뒤 교체가 필요하다면 아래 블루투스 스피커 비교글을 참고하세요. 이 글은 연결 후 무음에 관한 안내이며, TV의 HDMI ARC 연결이나 스피커 여러 대를 묶는 기능의 호환성은 별도로 확인해야 해요.
